Para buscar funciones o métodos dentro del archivo actual en Sublime Text(https://www.sublimetext.com/), el atajo principal es Goto Symbol: 
Windows / Linux: `Ctrl + R`
macOS: `Cmd + R`
## Otras formas de navegación:
- **En todo el proyecto**: Si necesitas buscar una función en cualquier archivo de tu proyecto abierto, usa `Ctrl + Shift + R` (o `Cmd + Shift + R` en Mac).
- **Menú Goto Anything**: Puedes presionar `Ctrl + P` y escribir el símbolo `@` seguido del nombre de la función.
- **Definición de función**: Para saltar directamente a donde se define una función sobre la que tienes el cursor, presiona `F12`.
